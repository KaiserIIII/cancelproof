All four issues are closed; that does not imply every current release contains the fix. Actual bounded subprocesses and separately installed reviewed artifacts were used. Raw snippets/logs are retained outside public source because they can contain local paths and upstream material.

These four results are native version-pinned reproductions, **not component replay** and not simulated Excel-style outputs. The capacity/lock triggers use the public library implementation in each wheel. The other two use the published snippet as captured in external evidence. No third-party expected assertion was edited to obtain a pass. All commands returned0; affected/fixed interpretation derives from the observed states, not subprocess exit code alone.

Exact source commits and wheel SHA256 are in `validation/HISTORY_ARTIFACTS.json`. Original environment installation, pip checks, inputs, stdout/stderr and source archives are in external `history/`. The signed PSF Python3.12.10 installer and source tag provenance are in `runtimes/` and `history/raw/`; the tool does not distribute that interpreter.

Historical repros are not shipped as automated product tests or production dependency recommendations. AnyIO4.15.1 is also the current optional HTTPX dependency in this acceptance environment, so its known concurrent-scope cancellation limitation remains relevant to integrations beyond the tested ASGI plans. Do not infer that CancelProof fixes third-party cancellation semantics. Trio/Linux historical variants and broad timing/platform repetitions were NOT RUN.
